# Brand Theme and Selected Works Update

## Theme

The visual system now follows the supplied Dreamweavers logo:

- Warm paper and white surfaces replace the previous neon-black base.
- Logo steel blue (`#4b7888`) is the primary accent.
- Charcoal (`#17191a`) carries typography and dark contrast sections.
- The original logo asset is preserved in `public/brand/dreamweavers-logo-source.jpg`.
- A cleaned mark derivative is used in the header/footer, and the supplied full logo appears in the intro/menu.
- Three.js materials, lights, particles, buttons, form styling, navigation, client strip, team cards and metadata visuals use the same palette.

## Selected Works

The former sticky browser-window card stack was removed. The replacement is an editorial project reel featuring:

- Alternating full-width project compositions
- Oversized project typography
- Animated poster/orbit artwork
- Woven line motion
- Service tags and content status
- Scroll-linked copy and visual movement
- Responsive single-column treatment on tablet/mobile

The content is still intentionally marked as pending client approval.

## Hydration warning

The `fdprocessedid` mismatch shown in the browser is injected by an autofill/password-manager browser extension before React hydrates. It is not generated by the application. To prevent the development overlay from reporting that extension mutation, `suppressHydrationWarning` is applied to the affected native form controls and menu button.
