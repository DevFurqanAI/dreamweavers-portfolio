# Theme V4 notes

## Changes

- Added targeted hydration-warning suppression to the Industry Modes buttons. The reported `fdprocessedid` attribute is injected by a browser extension or autofill tool, not generated by Next.js.
- Added a compact-on-scroll header state with a stronger glass surface and subtle elevation.
- Rebuilt Connected Capabilities as a visual systems section instead of a plain white card grid.
- Added six CSS-generated capability artworks. These are intentional abstract placeholders and can later be replaced by real product screenshots or commissioned 3D renders without changing the card architecture.
- Added animated background threads, nodes, grid movement and reduced-motion fallbacks.

## Image recommendation

Do not use generic stock photography for service cards. Keep the abstract visuals until Dreamweavers can supply real screenshots, interface captures, diagrams, or custom renders. Real project media should replace the artwork only when it proves the actual work.
